# ADR-004: 基於 OS Creation Date 比對的 Windows 孤兒行程安全清理

## 狀態
已通過 (Accepted)

## 背景
當控制器或主機異常重啟時，背景可能殘留未釋放鎖的訓練 Worker 進程。如果只比對 PID，由於 Windows PID 循環回收復用（PID Reuse）的特性，可能誤殺系統中其他不相干的進程。

## 決策
1. 訓練 Worker 啟動時取得自身的 OS 精準 Creation Time（Windows FileTime 格式，Unix 則讀取 `/proc/<pid>/stat` 啟動 ticks），並將其與 PID、CommandLine、run_id 寫入 `.pid` JSON 檔中。
2. 控制器在執行 `clean_orphans()` 時，讀取該 `.pid` 檔。利用 PowerShell `Get-CimInstance Win32_Process` 查詢當前運作進程的 CreationTime 與 CommandLine。
3. 只有在 (1) PID 吻合、(2) CreationTime 吻合且在容差範圍內、(3) 鎖已失效或由他人持有時，才執行強殺，否則安全跳過。

## 後果
- 徹底避免了 Windows 環境下 PID 復用導致的誤殺風險。
- 運維健壯性大幅提升，支援在不踩腳的情況下重啟控制器與進行多實例調度。
