# 思維框架提煉方法論

> 從原始資訊到可執行的心智模型，核心方法論

## 一、心智模型識別的三重驗證

一個論點要被認定為「心智模型」而非「隨口一說」，必須透過三重驗證：

### 驗證1: 跨域復現
同一個思維框架出現在此人討論的至少2個不同領域。

例：納瓦爾的「槓桿」概念——
- 在財富創造中談槓桿（程式碼、媒體、資本、勞動力）
- 在個人成長中談槓桿（特定知識 + 槓桿 = 複利）
- 在職業選擇中談槓桿（選擇有槓桿效應的工作）
→ 跨3個領域復現 → 這是真正的心智模型

### 驗證2: 有生成力
用這個模型可以推斷此人對新問題的可能立場。

例：如果芒格的「逆向思維」是心智模型——
- 面對「如何成功」→ 他會先想「如何確保失敗」
- 面對「如何投資」→ 他會先想「如何虧光所有錢」
→ 能生成新推斷 → 這是真正的心智模型

### 驗證3: 有排他性
不是所有聰明人都會這樣想，這個模型體現了此人的獨特視角。

例：「反脆弱」是塔勒布的，不是所有人都這樣看世界
→ 有區分度 → 這是值得提煉的心智模型

**如果一個觀點只透過了1重驗證** → 降級為「決策啟發式」而非「心智模型」
**如果一個觀點0重驗證都沒過** → 可能只是此人在特定場景說的話，不納入

## 二、表達DNA的量化方法

### 2.1 句式指紋

從此人的長文/演講中隨機抽取20個段落，統計：

| 維度 | 測量方式 |
|------|---------|
| 平均句長 | 字數/句數 |
| 疑問句比例 | 疑問句數/總句數 |
| 類比密度 | 類比數/千字 |
| 第一人稱使用率 | 「我」出現頻率 |
| 確定性語氣比例 | 「一定」「顯然」vs「也許」「可能」 |
| 轉折頻率 | 「但是」「然而」「不過」/千字 |

### 2.2 風格標籤

從以下維度打標：

```
正式 ←→ 口語
抽象 ←→ 具體
謹慎 ←→ 斷言
學術 ←→ 通俗
長句 ←→ 短句
鋪墊型 ←→ 結論先行
資料驅動 ←→ 敘事驅動
```

### 2.3 禁忌詞和口癖

- 此人從不用的詞 → 生成Skill時也不用
- 此人的口癖/高頻表達 → 適度使用（太多變成模仿秀）

## 三、矛盾處理原則

矛盾是人格的核心特徵，不是需要修復的Bug。

### 三種矛盾型別

1. **時間性矛盾**（觀點演化）
   - 此人早期說A，後來說B
   - 處理：記錄演化軌跡，標註「早期」「近期」
   - 在Skill中以「近期觀點」為主，但提及演化

2. **領域性矛盾**（不同場景不同規則）
   - 此人在工作中主張X，在生活中主張Y
   - 處理：分領域記錄，不強求統一
   - 這恰恰是深度的來源

3. **本質性張力**（價值觀內在衝突）
   - 例：既追求自由又重視紀律
   - 處理：明確記錄為「核心張力」
   - 這通常是此人最有意思的部分

### 錯誤的處理方式
- ❌ 選一邊忽略另一邊
- ❌ 編一個調和的解釋
- ❌ 假裝矛盾不存在

## 四、資訊不足時的處理

| 情況 | 處理 |
|------|------|
| 某個維度公開資訊很少 | 在Skill中標註「資訊不足，此維度為推測」 |
| 只有二手資訊 | 降低置資訊度，標註為「據[來源]報道」 |
| 資訊相互矛盾且無法判斷 | 並列呈現，讓使用者自行判斷 |
| 此人刻意不公開某方面 | 尊重邊界，在Skill中註明「此人對這個話題保持沉默」 |

---

## 五、人物Skill vs 主題Skill的區別

| 維度 | 人物Skill | 主題Skill |
|------|----------|----------|
| 核心 | 一個人的思維方式 | 一個領域的思維工具箱 |
| 心智模型來源 | 主要來自一個人 | 綜合多人視角 |
| 表達風格 | 模擬此人的表達 | 中性但專業 |
| 矛盾處理 | 保留個人內在矛盾 | 呈現流派間分歧 |
| 驗證方式 | 對比此人已知立場 | 對比領域內共識 |

## 六、質量自檢清單

生成Skill後，用以下問題自檢：

### 心智模型
- [ ] 每個模型都有至少2個不同領域的證據？
- [ ] 模型數量在3-7個之間？（太少=太淺，太多=沒提煉）
- [ ] 每個模型都有明確的應用場景和侷限？
- [ ] 模型之間有張力但不矛盾？

### 表達DNA
- [ ] 讀起來有辨識度，不像通用AI？
- [ ] 沒有過度模仿變成caricature？
- [ ] 抓住了核心特徵而非表面模仿？

### 決策啟發式
- [ ] 每條規則都有具體案例支撐？
- [ ] 可以被新情況觸發（不只適用於原始案例）？

### 誠實邊界
- [ ] 明確寫了做不到什麼？
- [ ] 標註了資訊源和調研時間？
- [ ] 承認了資訊不足的維度？

### 整體
- [ ] 用此人的眼睛看一個新問題，能得到有價值的視角？
- [ ] 不是此人原話的拼湊，而是框架的執行？
- [ ] 刪掉名字後，還能認出這是誰的思維方式？
